# STREAMLESS

**A Simple and Lightweight Streaming Studio for Windows.**

## Project Overview

STREAMLESS is a desktop streaming application designed to provide a simple, lightweight, and user-friendly live streaming experience.

Built for content creators and streamers, STREAMLESS focuses on gaming streams and camera live sessions, with customizable overlays, scene management, and essential streaming tools in one application.

Our goal is to make live streaming easier without the complexity of traditional streaming software.

## Features

- Gaming Streaming
- Camera Live
- Optional Facecam
- Custom Overlay Editor
- Ready-to-use Templates
- Scene & Source Management
- Audio & Video Configuration

## Platform

- Windows Desktop
- TikTok LIVE
- Youtube LIVE
- Twitch LIVE
- Facebook LIVE
- Custom RTMP

## Installation

### Windows Setup

**Step 1 — Run the Build Script**

1. Download or clone the STREAMLESS repository.
2. Extract the project files.
3. Open the `BUILD-EXE` folder.
4. Double-click `build-exe.bat`.
5. Wait until the build process is completed.

**Step 2 — Launch STREAMLESS**

1. Open the `dist` folder.
2. Open the `win-unpacked` folder.
3. Find `streamless.exe`.
4. Double-click `streamless.exe` to launch the application.

**Important Notes:**

- Do not close the build process before it finishes.
- Keep all files inside `win-unpacked` together.
- Do not move or delete application dependencies.
- If Windows displays a security warning, verify the source before proceeding.
